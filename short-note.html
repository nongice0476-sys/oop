📘 Python OOP — Class & Object (University Level)

ยึดหัวข้อเดิมของอาจารย์ แต่เพิ่มการวิเคราะห์ code และ attribute behavior

1) Class & Object

class Student: pass s1 = Student() s2 = Student()

Class = แม่แบบ • Object/Instance = สิ่งที่สร้างจาก class • s1 และ s2 เป็นคนละ object

2) Class Attribute vs Object Property

class Student: university = "KMITL" s1 = Student() s2 = Student() s1.university = "ABC"
s1.university → ABC
s2.university → KMITL
Student.university → KMITL
เหตุผล: property ของ object สามารถ บัง (shadow) class attribute ที่ชื่อเดียวกัน

3) Attribute Lookup ที่ควรเข้าใจ

เมื่ออ่าน obj.x ในระดับบทนี้ ให้คิดเป็นลำดับ:

1) obj มี property x ของตัวเองไหม? → ถ้ามี: ใช้ค่านั้น 2) ถ้าไม่มี: class มี attribute x ไหม? → ถ้ามี: ใช้ค่าจาก class

4) Method และ self

class Box: value = 2 def show(self): return self.value b = Box() b.value = 9 print(b.show()) # 9

self อ้างถึง object ที่กำลังเรียก method ดังนั้น self.value จึงอ่าน state ของ object นั้นก่อน

5) a.f() กับ A.f(a)

class A: def f(self): return self a = A() a.f() A.f(a)

ในเชิงแนวคิด ทั้งสองกรณีส่ง object a เข้า parameter ตัวแรกของ method

6) Aliasing — จุดที่ข้อสอบชอบหลอก

a = A() b = a b.x = 10 print(a.x) # 10

b = a ไม่ได้สร้าง object ใหม่ แต่ทำให้มี 2 ชื่ออ้างถึง object เดียวกัน

7) del property vs del object reference

del obj.x

ลบ property x ของ object

del obj

ลบชื่อ/reference obj

ถ้ายังมีชื่ออื่นอ้าง object เดิมอยู่ เช่น b = obj แล้ว del obj → b ยังอาจใช้งาน object เดิมได้

8) del แล้ว class attribute โผล่กลับมา

class A: x = 1 a = A() a.x = 9 print(a.x) # 9 del a.x print(a.x) # 1

เพราะ instance property x ถูกลบ แล้ว lookup กลับไปเจอ class attribute x

9) Naming & pass

Class Naming
PascalCase: StudentRecord, BankAccount
pass
placeholder เพื่อให้ block ว่าง syntax ถูกต้อง

10) Checklist ก่อนตอบข้อเขียน

ตอบให้ครบ 4 อย่าง: (1) มี object กี่ตัว (2) ชื่อไหนเป็น alias (3) attribute มาจาก object หรือ class (4) del กำลังลบ property หรือ reference
