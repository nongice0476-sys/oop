📘 Python OOP — Class & Object

ยึดเฉพาะเนื้อหาที่อาจารย์สอน

Class & Object

class Student: pass s1 = Student() s2 = Student()

Class = แม่แบบ • Object = instance ที่สร้างจาก class

Class Attribute

class Student: university = "KMITL"

ประกาศใน class body และใช้ร่วมกันได้จนกว่า object จะมี property ชื่อเดียวกันมาบัง

Method และ self

class Student: def show(self): return self.university

self อ้างถึง object ที่เรียก method

Object Property

s1.name = "Ann" s1.name = "May" del s1.name

กำหนด • แก้ • ลบ property ผ่าน object ได้โดยตรง

Attribute Lookup

class A: x = 1 a = A() a.x = 9 # object property บัง class attribute del a.x # กลับไปเห็น A.x = 1

Alias / Reference

a = A() b = a

a และ b อ้าง object เดียวกัน การแก้ state ผ่านชื่อหนึ่งจึงเห็นผลจากอีกชื่อ

pass

pass คือ placeholder ที่ทำให้ block ว่างยังมี syntax ถูกต้อง

Programming Testcases

กด Run เพียงครั้งเดียว ระบบจะรัน Testcases ทั้งหมดและเช็คทีละเคสอัตโนมัติ

เกณฑ์ตรวจโค้ดเป็น Black-box: ไม่สนว่าเขียนด้วยวิธีไหน ไม่สนชื่อ variable หรือรูปแบบภายใน ขอเพียง output ของแต่ละ Testcase ตรงกับตัวอย่างก็ถือว่าผ่าน
