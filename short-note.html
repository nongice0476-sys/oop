📘 Python OOP — Class and Object

ยึดเฉพาะหัวข้อที่อาจารย์สอนแล้ว

1) Create a Class in Python

class Student: pass

class = keyword • ชื่อ class ตามด้วย : • block ต้องเยื้อง

2) Create Object of a Class

s1 = Student() s2 = Student()

Object หรือ Instance คือสิ่งที่สร้างจาก class

3) Class Attributes

class Student: school = "KMITL" print(Student.school)

Class attribute ประกาศตรงใน class body และเป็นข้อมูลระดับ class

4) Class Methods

class Student: def greet(self): print("Hello") s1 = Student() s1.greet()

Method คือ function ที่อยู่ใน class และ instance method มักใช้ self เป็น parameter แรก

5) Class Naming Convention

แนะนำ
Student
BankAccount
CourseRegistration
หลักจำ
ใช้ PascalCase สำหรับชื่อ class

6) pass Statement in Class

class EmptyClass: pass

pass ไม่ทำงานอะไร ใช้เป็น placeholder เมื่อยังไม่เขียนรายละเอียดใน block

7) Object Properties

s1.name = "Ann" s1.age = 20 print(s1.name) print(s1.age)

7.2 Modify Object Properties

s1.name = "May" s1.age = 21

แก้ property ด้วย assignment ค่าใหม่

7.3 Delete Object Properties

del s1.age

ลบ property เฉพาะตัวด้วย del object.property

8) Delete Objects

del s1

ลบชื่อ/reference ของ object ที่กำหนด

คู่ที่ห้ามสับสน

Class vs Object
Class = แม่แบบ
Object = instance
del s1.age vs del s1
อันแรก = ลบ property
อันหลัง = ลบ object reference
Class Attribute vs Object Property
Class attribute = ระดับ class
Object property = ข้อมูลของแต่ละ object
