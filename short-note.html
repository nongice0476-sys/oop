📘 OOP Year 2 — Short Note

CorePolymorphismAbstract/InterfaceSOLIDJava Pitfalls

1) Core OOP

Class / Object
Class = แม่แบบ • Object = instance
State = fields • Behavior = methods
Encapsulation
ซ่อน state ด้วย private และเปิด behavior ที่ควบคุม invariant
ไม่ใช่แค่ private + getter/setter ทุกตัว
Inheritance
ใช้เมื่อเป็น is-a จริง ๆ
Subclass ควรแทน superclass ได้อย่างสมเหตุสมผล
Composition
has-a relationship
มักยืดหยุ่นกว่า inheritance ลึก ๆ

2) Overloading / Overriding / Polymorphism

แนวคิดจำเร็วตัดสินเมื่อ
Overloadingชื่อเดียว parameter list ต่างCompile time
OverridingSubclass เปลี่ยน implementationRuntime
Polymorphismเขียนต่อ abstractionRuntime behavior
Animal a = new Dog(); a.speak(); // Dog.speak()

3) Abstract Class vs Interface

Abstract Class
มี state/constructor/concrete methods ร่วมได้
เหมาะ base implementation ในสายสืบทอด
Interface
กำหนด contract/capability
class implement ได้หลาย interface

4) Java ที่ออกสอบบ่อย

this / super
this = instance ปัจจุบัน
this(...) = constructor class เดียวกัน
super(...) = constructor superclass
static
เป็นของ class
static method ไม่มี this
final
final variable = reassign ไม่ได้
final method = override ไม่ได้
final class = extend ไม่ได้
equals/hashCode
== เทียบ identity
equals = logical equality
equal objects ต้องมี hashCode เท่ากัน

5) SOLID

S — SRP
responsibility หลักชัดเจน
O — OCP
เปิดให้ขยาย ปิดต่อการแก้เดิมโดยไม่จำเป็น
L — LSP
subtype ควรแทน base type ได้
I — ISP
interface เล็กและตรง client
D — DIP
พึ่ง abstraction

6) Exception / Collections / Generics

Exception
Checked: catch หรือ throws
อย่า swallow exception
try-with-resources สำหรับ AutoCloseable
Collections
List = ordered/duplicate
Set = unique
Map = key-value
Generics
compile-time type safety
List<Dog> ไม่ใช่ subtype ของ List<Animal>

7) Design Checklist

ถามก่อนตอบ: ใครรับผิดชอบอะไร? • is-a หรือ has-a? • client พึ่ง abstraction หรือ concrete? • state ถูกปกป้องหรือไม่? • เพิ่ม feature ใหม่ต้องแก้หลาย class หรือเปล่า?
interface PaymentMethod { void pay(double amount); } class PromptPay implements PaymentMethod { ... } class CreditCard implements PaymentMethod { ... }
